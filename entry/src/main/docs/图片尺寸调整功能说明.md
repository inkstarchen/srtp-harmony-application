# 图片尺寸拖动调整功能

## 功能说明

实现了通过滑块(Slider)面板调整笔记中图片尺寸的功能，替代了之前的对话框输入方式，提供更直观的拖动调整体验。

## 实现方式

### 1. 触发方式
- 长按图片 → 选择"编辑尺寸"菜单项
- 弹出尺寸调整面板（带半透明遮罩）

### 2. 调整面板特性
- **宽度滑块**: 范围 100-800px，步进 10px
- **高度滑块**: 范围 50-600px，步进 10px
- **锁定宽高比**: 默认开启，拖动宽度时自动计算高度
- **预设比例**: 1:1、4:3、16:9 快速设置
- **实时更新**: 拖动滑块时图片尺寸实时更新

### 3. 尺寸持久化
- 调整后的尺寸自动保存到 `style.size` 和 `imageInfo`
- 加载笔记时恢复保存的尺寸

## 修改的文件

1. **EditorController.ets**
   - 修改 `editImageSize()` 方法，通过回调通知UI显示面板
   - 添加 `onImageSizeEditRequest` 回调属性
   - 将 `updateImageSize()` 改为 public 方法

2. **ImageSizePanel.ets** (新建)
   - 独立的尺寸调整面板组件
   - 包含宽度/高度滑块、锁定宽高比开关、预设比例按钮
   - 支持实时尺寸变更回调

3. **NotePage.ets**
   - 添加尺寸面板相关状态变量
   - 设置 `onImageSizeEditRequest` 回调
   - 在 build() 中添加面板渲染逻辑
   - 实现拖动时的实时更新

## 使用流程

```
1. 用户在编辑器中长按图片
2. 弹出操作菜单，选择"编辑尺寸"
3. 显示尺寸调整面板（带遮罩）
4. 拖动宽度或高度滑块
   - 图片尺寸实时更新
   - 锁定宽高比时自动计算另一维度
5. 点击"确定"关闭面板
   - 尺寸信息已自动保存
6. 点击"取消"或点击遮罩关闭面板
   - 保持最后的拖动值
```

## 技术要点

- 使用 `RichEditorController.updateSpanStyle()` 实时更新图片尺寸
- 通过回调机制实现 EditorController 和 UI 层的解耦
- Slider 组件的 `onChange` 和 `onTouch` 事件确保拖动过程中的实时响应
- 尺寸信息通过 `contentConvert.ets` 自动持久化到 JSON 文件
