## 一、设计目标与背景

### 1.1 为什么需要 2D/3D 融合？

传统应用开发中，2D UI 和 3D 场景是两个独立的世界：

| 传统模式 | 融合模式 |
|----------|----------|
| 2D UI 负责交互和信息展示 | 2D UI 组件在 3D 空间中有对应替身 |
| 3D 场景负责视觉效果 | 3D 物理模拟结果影响 2D UI 布局 |
| 两者分离，无法交互 | 用户通过 2D 操作直接控制 3D 物体 |

**核心价值**：让用户在熟悉的 2D 交互方式下，自然体验到 3D 空间带来的沉浸感和真实物理反馈。

### 1.2 设计原则

```
┌─────────────────────────────────────────────────────────┐
│                    设计原则                               │
│                                                         │
│  1. 透明性                                               │
│     开发者创建 2D 组件时，自动建立 3D 映射                │
│     无需手动管理两套坐标系统                             │
│                                                         │

│  3. 双向性                                               │

│     3D 影响 2D：物理反馈、视觉效果                        │
│                                                         │
│  4. 可扩展性                                             │
│     核心机制独立于具体业务                               │

└─────────────────────────────────────────────────────────┘
```

## 三、核心功能详解

### 3.1 功能一：2D UI ↔ 3D Node 双向映射

#### 3.1.1 功能描述

建立 2D ArkUI 组件与 3D Scene 节点之间的一一对应关系，使得：
- 操作 2D UI 时，自动影响对应的 3D 物体
- 3D 物理模拟结果，可以反馈到 2D UI 的显示状态

#### 3.1.2 实现方案

**数据结构设计**：

```typescript
// GlobalSceneProxy.ets
@ObservedV2
export class SceneProxy {
  // 核心映射表
  private uiToNodeIdMap: Map<string, number> = new Map();
  
  // 映射注册方法
  registerUI2DTo3D(uiId: string, nodeId: number) {
    this.uiToNodeIdMap.set(uiId, nodeId);
    console.info(`[UI2D→3D] 注册映射: '${uiId}' → nodeId ${nodeId}`);
  }
  
  // 查询方法
  get3DNodeId(uiId: string): number | undefined {
    return this.uiToNodeIdMap.get(uiId);
  }
}
```

**映射建立流程**：

```
ArkTS 侧创建 2D UI 组件
  │
  │  示例：NotePage 中的编辑区域
  │  Column()
  │    .id("editUI")
  │    .width("80%")
  │    .height("80%")
  │
  ▼

  │
  ├─ 步骤 1: 加载预制 Plane 模型
  │    resource = this.resMap.get('card')
  │    resScene = await Scene.load(resource)
  │
  ├─ 步骤 2: 导入到当前场景
  │    node = this.scene.importNode(reName, parent, this.scene.root)
  │
  ├─ 步骤 3: 设置初始位置和缩放
  │    node.scale.x = scale.x
  │    node.scale.y = scale.y
  │    node.position.z = -1
  │
  ├─ 步骤 4: 注册到物理系统
  │    id = this.physicalSystem.registerNode(node, true)
  │    → 返回物理节点 ID
  │
  └─ 步骤 5: 存储映射关系
       this.registerUI2DTo3D(uiId, nodeId)
```

**代码实现（摘自 GlobalSceneProxy.ets）**：

```typescript
async addUIPlane(name: string, scale: Vec2): Promise<number | undefined> {
  // 添加 3D 平面节点并获取物理 ID
  let nodeId = await this.addNodeWithScaleReturnId(
    'card',        // 资源名
    'Plane',       // 节点名
    name,          // 重命名为 uiId
    scale          // 缩放比例
  );
  
  if (nodeId !== undefined) {
    // 注册 2D→3D 映射
    this.registerUI2DTo3D(name, nodeId);
  }
  
  return nodeId;
}
```

#### 3.1.3 使用示例

```typescript
// NotePage.ets 中的实际应用

// 1. 初始化时创建映射
onTouch((event) => {
  if (!this.init) {
    // 获取 2D UI 尺寸
    let uiInfo = this.getUIContext().getComponentUtils()
                     .getRectangleById('editUI');
    
    // 计算相对缩放比例
    let scale: Vec2 = {
      x: uiInfo.size.width / viewportHeight,
      y: uiInfo.size.height / viewportHeight
    };
    
    // 创建 3D 替身并建立映射
    this.sceneProxy.addUIPlane('editUI', scale);
    
    this.init = true;
  }
})

// 2. 运行时同步位置
syncUIto3D(uiId: string) {
  // 获取 3D Node ID
  const nodeId = this.sceneProxy.get3DNodeId(uiId);
  
  // 获取 2D UI 实时位置
  const uiInfo = this.uiContext.getComponentUtils()
                     .getRectangleById(uiId);
  
  // 坐标转换：屏幕坐标 → 3D 世界坐标
  const posX = ((uiCenterX - centerX) / vpHeight) * worldScale;
  const posY = -((uiCenterY - centerY) / vpHeight) * worldScale;
  
  // 发送更新指令
  this.sceneProxy.eventQueue.updateTransform(
    nodeId,
    { x: posX, y: posY, z: -1.0 },
    { x: scaleX, y: scaleY }
  );
}
```

#### 3.1.4 关键设计要点

| 要点 | 说明 | 代码体现 |
|------|------|----------|
| **唯一标识** | 每个 2D 组件必须有唯一 ID | `.id("editUI")` |
| **延迟初始化** | 等待 2D 布局完成后再创建 3D 映射 | `onTouch` 首次触发时 |
| **坐标转换** | 屏幕坐标需转换为 3D 世界坐标 | 归一化计算 + worldScale |
| **异步处理** | 3D 节点创建是异步的 | `async/await` 模式 |
| **映射持久化** | 映射关系在场景生命周期内保持 | Map 结构存储 |

### 3.2 功能二：触摸事件驱动物理模拟

#### 3.2.1 功能描述

将用户在 2D 屏幕上的触摸操作，转换为 3D 物理引擎可以理解的事件，驱动物理模拟。

#### 3.2.2 触摸事件类型

```typescript
// EventTypes.ets 定义

export enum EventType {
  // 基础触摸事件
  TOUCH_DOWN = 1,      // 手指按下
  TOUCH_MOVE = 2,      // 手指移动
  TOUCH_UP = 3,        // 手指抬起
  
  // 交互事件
  RAYCAST_REQUEST = 100,    // 射线检测请求
  ROTATE_REQUEST = 101,     // 旋转请求
  SET_PROPERTY_REQUEST = 102, // 属性设置
  
  // 系统事件
  RESET_GRAVITY = 103,      // 重力重置
}

// 事件命令结构
export interface EventCommand {
  type: EventType;           // 事件类型
  priority: number;          // 优先级 (0=HIGH, 1=NORMAL, 2=LOW)
  nodeId: number;            // 目标节点 ID
  timestamp: number;         // 时间戳
  data: number[];            // 附加数据
}
```

#### 3.2.3 事件队列管理

**双缓冲机制**：

```typescript
// EventQueueManager.ets

@ObservedV2
export class EventQueueManager {
  // 双缓冲队列
  private writeQueues: EventCommand[][] = [
    [], // HIGH 优先级
    [], // NORMAL 优先级
    []  // LOW 优先级
  ];
  
  private readQueues: EventCommand[][] = [
    [],
    [],
    []
  ];
  
  // 事件合并优化
  private lastTouchMove: EventCommand | null = null;
  private pendingRayCast: EventCommand | null = null;
  
  // 推送事件
  push(event: EventCommand) {
    this.writeQueues[event.priority].push(event);
  }
  
  // 交换队列（每帧调用）
  swapQueues() {
    let temp = this.readQueues;
    this.readQueues = this.writeQueues;
    this.writeQueues = temp;
    
    // 清空写入队列
    this.writeQueues.forEach(q => q.length = 0);
    
    // 重置合并标记
    this.lastTouchMove = null;
    this.pendingRayCast = null;
  }
}
```

**事件合并优化**：

```typescript
// TouchMove 事件合并（避免队列膨胀）
pushTouchMove(x: number, y: number): void {
  if (this.lastTouchMove) {
    // 只更新已有事件的数据，不创建新事件
    this.lastTouchMove.data = [0, x, y];
  } else {
    let e: EventCommand = {
      type: EventType.TOUCH_MOVE,
      priority: getDefaultPriority(EventType.TOUCH_MOVE),
      nodeId: 0,
      timestamp: systemDateTime.getUptime(),
      data: [0, x, y]
    };
    this.push(e);
    this.lastTouchMove = e; // 记录引用
  }
}

// Raycast 事件合并（只保留最新）
pushRayCastRequest(fx: number, fy: number): void {
  if (this.pendingRayCast) {
    this.pendingRayCast.data = [fx, fy];
  } else {
    let e: EventCommand = {
      type: EventType.RAYCAST_REQUEST,
      priority: getDefaultPriority(EventType.RAYCAST_REQUEST),
      nodeId: 0,
      timestamp: systemDateTime.getUptime(),
      data: [0, fx, fy]
    };
    this.pendingRayCast = e;
    this.push(e);
  }
}
```

#### 3.2.4 射线检测实现

**功能描述**：将屏幕触摸坐标转换为 3D 射线，检测命中的 3D 物体。

**坐标转换公式**：

```typescript
// GlobalSceneProxy.ets

rayCast(pos: Vec2, ui: UIContext) {
  // 屏幕坐标 → 视锥体坐标转换
  let fx = (2 * ui.vp2px(pos.x) / SceneProxy.sceneSize.width) - 1;
  let fy = 1 - (2 * ui.vp2px(pos.y) / SceneProxy.sceneSize.height);
  
  // 发送射线检测请求
  this.eventQueue.pushRayCastRequest(fx, fy);
}
```

**转换原理**：

```
屏幕坐标系                    视锥体坐标系
┌─────────────┐              ┌─────────────┐
│ (0,0)       │              │ (-1, 1)     │
│      ●      │              │             │
│   (触摸点)   │    ────►     │      ●      │
│             │              │   (fx, fy)   │
│       (w,h) │              │     (1,-1)  │
└─────────────┘              └─────────────┘

转换公式：
  fx = (2 * posX / width) - 1   → 范围 [-1, 1]
  fy = 1 - (2 * posY / height)  → 范围 [-1, 1]
```

**C++ 端射线检测**（摘自 physics/collision.cpp）：

```cpp
// 射线 vs AABB 检测（slab 方法）
bool RaycastAABB(const Ray& ray, const AABB& aabb, float& tmin) {
    float tmin_temp = -FLT_MAX;
    float tmax_temp = FLT_MAX;
    
    for (int i = 0; i < 3; i++) {
        if (fabs(ray.direction[i]) < EPSILON) {
            // 射线平行于 slab
            if (ray.origin[i] < aabb.min[i] || ray.origin[i] > aabb.max[i]) {
                return false;
            }
        } else {
            float ood = 1.0f / ray.direction[i];
            float t1 = (aabb.min[i] - ray.origin[i]) * ood;
            float t2 = (aabb.max[i] - ray.origin[i]) * ood;
            
            if (t1 > t2) { float temp = t1; t1 = t2; t2 = temp; }
            
            tmin_temp = max(tmin_temp, t1);
            tmax_temp = min(tmax_temp, t2);
            
            if (tmin_temp > tmax_temp) return false;
        }
    }
    
    tmin = tmin_temp;
    return true;
}
```

#### 3.2.5 触摸旋转控制

**功能描述**：用户拖拽屏幕时，选中的 3D 物体跟随旋转。

```typescript
// TouchRotate.ets

@ObservedV2
export class TouchRotate {
  target: Node | undefined; // 目标 3D 节点
  
  update(touch: Touch): Quaternion {
    if (!this.target) return {x:0, y:0, z:0, w:0};
    
    if (touch.active) {
      // 计算触摸移动距离
      let distance: Vec2 = {
        x: touch.curPos.x - touch.lastPos.x,
        y: touch.curPos.y - touch.lastPos.y
      };
      
      // 转换为旋转增量
      const deltaRot = rotationFromTouchDelta(distance.x, distance.y);
      
      // 新旋转 = Δq × 当前旋转
      return mulQuat(deltaRot, this.target.rotation);
    }
    
    return {x:0, y:0, z:0, w:0};
  }
}

// 触摸增量转旋转
const ROTATE_SPEED = 0.05; // 灵敏度

export function rotationFromTouchDelta(
  dx: number,
  dy: number
): Quaternion {
  // X 方向滑动 → 绕 Y 轴旋转
  const qYaw = fromAxisAngle(
    { x: 0, y: 1, z: 0 },
    dx * ROTATE_SPEED
  );
  
  // Y 方向滑动 → 绕 X 轴旋转
  const qPitch = fromAxisAngle(
    { x: 1, y: 0, z: 0 },
    dy * ROTATE_SPEED
  );
  
  // 先 pitch 再 yaw（顺序重要）
  return mulQuat(qYaw, qPitch);
}

// 轴角转四元数
export function fromAxisAngle(axis: Vec3, angleRad: number): Quaternion {
  let n = normalizeVec3(axis);
  let half = angleRad * 0.5;
  let s = Math.sin(half);
  
  return {
    x: n.x * s,
    y: n.y * s,
    z: n.z * s,
    w: Math.cos(half)
  };
}
```

### 3.3 功能三：物理引擎驱动的 2D/3D 交互

#### 3.3.1 功能描述

让 2D UI 组件在 3D 空间中作为物理体参与物理模拟，获得重力、碰撞、惯性等真实物理效果。

#### 3.3.2 物理节点注册

**数据转换流程**：

```typescript
// PhysicsAdapter.ets

export enum ShapeType {
  AABB,    // 定向包围盒
  SPHERE,  // 球体
}

export interface PhysicsData {
  position: Vec3;      // 位置
  rotation: Vec4;      // 四元数旋转
  scale: Vec3;         // 缩放
  extent: Vec3;        // 包围盒范围
  shapeType: number;   // 形状类型
  isStatic: number;    // 是否静态（1=静态，0=动态）
}

export class PhysicsAdapter {
  static ToPhysicsData(node: Node, type: ShapeType, isStatic: boolean): PhysicsData {
    const position = node.position;
    const rotation = node.rotation as Vec4;
    const scale = node.scale;
    let geom = node as Geometry;
    let aabb = geom.mesh.aabb;
    
    // 应用 scale 到 extent
    let extent = {
      x: Math.abs((aabb.aabbMax.x - aabb.aabbMin.x) / 2 * scale.x),
      y: Math.abs((aabb.aabbMax.y - aabb.aabbMin.y) / 2 * scale.y),
      z: Math.abs((aabb.aabbMax.z - aabb.aabbMin.z) / 2 * scale.z)
    } as Vec3;
    
    // 防止 extent 为 0
    const MIN_EXTENT = 0.001;
    if (extent.x < MIN_EXTENT) extent.x = MIN_EXTENT;
    if (extent.y < MIN_EXTENT) extent.y = MIN_EXTENT;
    if (extent.z < MIN_EXTENT) extent.z = MIN_EXTENT;
    
    // 球体形状特殊处理
    let shapeType: number = 0;
    if (type == ShapeType.SPHERE) {
      shapeType = 1;
      let max = Math.max(extent.x, extent.y, extent.z);
      extent.x = max;
      extent.y = max;
      extent.z = max;
    }
    
    return {
      position: position,
      rotation: rotation,
      scale: scale,
      extent: extent,
      shapeType: shapeType,
      isStatic: isStatic ? 1 : 0,
    } as PhysicsData;
  }
}
```

### 3.4 功能四：视差倾斜与透视变换

#### 3.4.1 功能描述

当 2D UI 组件在屏幕上位置变化时，自动产生自然的 3D 倾斜效果，模拟真实透视视觉体验。

#### 3.4.2 核心数学原理

```
视锥体模型：

                    Camera (0, 0, -d)
                         ↓
                    ╱─────────╲
                   ╱           ╲
                  ╱             ╲
                 ╱   ┌─────────┐ ╲
                ╱    │  Plane  │  ╲
               ╱     │    ●    │   ╲  ← 物体位置 (offsetX, offsetY, 0)
              ╱      │         │    ╲
             ╱       └─────────┘     ╲

视线方向向量 = 物体位置 - 相机位置
            = (offsetX, offsetY, 0) - (0, 0, -distance)
            = (offsetX, offsetY, distance)

倾斜角度计算：
  tiltX = atan2(offsetY, distance)    // X 轴倾斜
  tiltY = -atan2(offsetX, distance)   // Y 轴倾斜（方向相反）

透视因子：
  perspectiveFactor = tan(fovy / 2) / distance
```

#### 3.4.3 透视变换矩阵计算

```typescript
// PerspectiveTransform.ets

export interface CalTransformParams {
  fovy: number;              // 相机垂直视场角（弧度）
  cameraDistance: number;    // 相机到平面的距离（像素）
  rotation: Vec3;            // 组件旋转（弧度）
  offset: Vec2;              // 组件偏移（像素）
  planeSize?: Size;          // 平面尺寸
}

export class PerspectiveTransform {
  
  /**
   * 计算视差倾斜角度
   */
  static calculateParallaxTilt(
    offset: Vec2,
    distance: number,
    planeSize: Size
  ): Vec3 {
    const dirX = offset.x;
    const dirY = offset.y;
    const dirZ = distance;
    
    // 视线方向的角度
    const tiltX = Math.atan2(dirY, dirZ);
    const tiltY = -Math.atan2(dirX, dirZ); // Y 轴相反
    
    return { x: tiltX, y: tiltY, z: 0 };
  }
  
  /**
   * 计算透视增强因子
   */
  static calculatePerspectiveFactors(
    offset: Vec2,
    distance: number,
    planeSize: Size
  ): PerspectiveFactors {
    // 到中心的距离
    const distToCenter = Math.sqrt(
      offset.x * offset.x + offset.y * offset.y
    );
    
    // 最大偏移距离
    const maxOffset = Math.sqrt(
      Math.pow(planeSize.width / 2, 2) +
      Math.pow(planeSize.height / 2, 2)
    );
    
    // 透视增强：中心为 1，边缘为 2
    const perspectiveBoost = 1 + (distToCenter / maxOffset);
    
    // 缩放因子（边缘物体看起来更小）
    const actualDepth = Math.sqrt(
      distToCenter * distToCenter + distance * distance
    );
    const scale = distance / actualDepth;
    
    return { scale, perspectiveBoost };
  }
  
  /**
   * 计算完整透视变换矩阵
   */
  static calculateTransformMatrix(params: CalTransformParams):
    [number, number, number, number,
     number, number, number, number,
     number, number, number, number,
     number, number, number, number] {
    
    const fovy = params.fovy;
    const cameraDistance = params.cameraDistance;
    const rotation = params.rotation;
    const offset = params.offset;
    const planeSize = params.planeSize;
    
    // 1. 基础透视因子
    const basePerspectiveFactor = 
      PerspectiveTransform.calculatePerspectiveFactor(fovy, cameraDistance);
    
    // 2. 视差倾斜
    let parallaxTilt: Vec3 = { x: 0, y: 0, z: 0 };
    let perspectiveBoost = 1;
    
    if (planeSize) {
      parallaxTilt = PerspectiveTransform.calculateParallaxTilt(
        offset, cameraDistance, planeSize
      );
      
      const factors = PerspectiveTransform.calculatePerspectiveFactors(
        offset, cameraDistance, planeSize
      );
      perspectiveBoost = factors.perspectiveBoost;
    }
    
    // 3. 组合旋转：视差倾斜 + 自身旋转
    const combinedRotX = rotation.x + parallaxTilt.x;
    const combinedRotY = rotation.y + parallaxTilt.y;
    const combinedRotZ = rotation.z || 0;
    
    const cosX = Math.cos(combinedRotX);
    const sinX = Math.sin(combinedRotX);
    const cosY = Math.cos(combinedRotY);
    const sinY = Math.sin(combinedRotY);
    const cosZ = Math.cos(combinedRotZ);
    const sinZ = Math.sin(combinedRotZ);
    
    // 4. 透视增强
    const p = basePerspectiveFactor * perspectiveBoost;
    
    // 5. 计算 4×4 矩阵（列主序）
    const m00 = cosY * cosZ + sinX * sinY * sinZ;
    const m01 = -cosX * sinZ;
    const m02 = sinY * cosZ - sinX * cosY * sinZ;
    const m03 = p * m02; // 透视分量
    
    const m10 = cosY * sinZ - sinX * sinY * cosZ;
    const m11 = cosX * cosZ;
    const m12 = sinY * sinZ + sinX * cosY * cosZ;
    const m13 = p * m12; // 透视分量
    
    const m20 = -cosX * sinY;
    const m21 = sinX;
    const m22 = cosX * cosY;
    const m23 = p * m22; // 透视分量
    
    const m30 = offset.x;
    const m31 = offset.y;
    const m32 = -cameraDistance;
    const m33 = 1;
    
    return [
      m00, m01, m02, m03,
      m10, m11, m12, m13,
      m20, m21, m22, m23,
      m30, m31, m32, m33
    ];
  }
}
```

### 3.6 功能六：相机视野布局系统

#### 3.6.1 功能描述

根据 3D 相机的视野范围，自动计算网格布局参数，使物体刚好填满屏幕。

#### 3.6.2 相机视野计算

```typescript
// CameraViewUtils.ets

export interface CameraConfig {
  position: Vec3;       // 相机位置
  fov: number;          // 视野角度（弧度）
  aspectRatio: number;  // 宽高比
  nearClip: number;     // 近裁剪面
  farClip: number;      // 远裁剪面
}

/**
 * 计算相机在指定 Z 距离处的视野范围
 */
export function getCameraFrustumAtZ(
  zDistance: number, 
  camera: CameraConfig
): [number, number] {
  // 半高 = 距离 × tan(fov / 2)
  const halfHeight = zDistance * Math.tan(camera.fov / 2);
  
  // 半宽 = 半高 × 宽高比
  const halfWidth = halfHeight * camera.aspectRatio;
  
  return [halfWidth, halfHeight];
}

/**
 * 根据相机视野生成填满屏幕的网格布局配置
 */
export function generateLayoutConfigForCameraView(
  targetZ: number,       // 网格所在的 Z 坐标
  rows: number,          // 行数
  cols: number,          // 列数
  spacingX: number = 0.1,
  spacingY: number = 0.1,
  cellDepth: number = 0.1,
  camera: CameraConfig = DEFAULT_CAMERA
): LayoutConfig {
  // 1. 计算 Z 轴距离
  const zDistance = targetZ - camera.position.z;
  
  // 2. 获取该距离处的视野半宽和半高
  const size = getCameraFrustumAtZ(zDistance, camera);
  const halfWidth = size[0];
  const halfHeight = size[1];
  const visibleWidth = halfWidth * 2;
  const visibleHeight = halfHeight * 2;
  
  // 3. 计算格子大小（刚好填满可见区域）
  const cellWidth = (visibleWidth - (cols - 1) * spacingX) / cols;
  const cellHeight = (visibleHeight - (rows - 1) * spacingY) / rows;
  
  // 4. 计算原点（左上角，居中）
  const originX = -visibleWidth / 2 + cellWidth / 2;
  const originY = visibleHeight / 2 - cellHeight / 2;
  
  return {
    rows,
    cols,
    cellWidth,
    cellHeight,
    cellDepth,
    spacingX,
    spacingY,
    origin: { x: originX, y: originY, z: targetZ },
    zPosition: targetZ,
    fillOrder: FillOrder.ROW_MAJOR
  };
}
```

```typescript
/**
 * 在相机视野范围内生成随机位置
 */
export function getRandomPositionInCameraView(
  minZ: number = -1,
  maxZ: number = -2,
  camera: CameraConfig = DEFAULT_CAMERA
): Vec3 {
  // 随机 Z 距离
  const zDistance = Math.random() * (maxZ - minZ) + minZ;
  
  // 获取该距离处的视野范围
  const view = getCameraFrustumAtZ(zDistance, camera);
  const halfWidth = view[0];
  const halfHeight = view[1];
  
  // 随机 X 和 Y（在视野范围内）
  const randomX = (Math.random() * 2 - 1) * halfWidth;
  const randomY = (Math.random() * 2 - 1) * halfHeight;
  
  // 计算世界坐标
  return {
    x: camera.position.x + randomX,
    y: camera.position.y + randomY,
    z: camera.position.z + zDistance
  };
}
```

## 五、性能优化策略

### 5.1 事件合并

```typescript
// 问题：TouchMove 事件频率过高，导致队列膨胀

// 解决方案：只保留最新的 TouchMove 事件
pushTouchMove(x: number, y: number): void {
  if (this.lastTouchMove) {
    // 更新已有事件，不创建新事件
    this.lastTouchMove.data = [0, x, y];
  } else {
    // 首次创建
    let e: EventCommand = { ... };
    this.push(e);
    this.lastTouchMove = e;
  }
}

效果：
  优化前：每秒 60 个 TouchMove 事件 → 队列长度 60
  优化后：每秒 1 个 TouchMove 事件 → 队列长度 1
```

### 5.2 双缓冲机制

```typescript
// 问题：ArkTS 写入和 C++ 读取冲突

// 解决方案：双缓冲队列
swapQueues() {
  let temp = this.readQueues;
  this.readQueues = this.writeQueues;  // C++ 读取上一帧事件
  this.writeQueues = temp;             // ArkTS 写入新事件
  
  this.writeQueues.forEach(q => q.length = 0); // 清空
}

时序：
  帧 N:
    ArkTS 写入 writeQueues
    C++ 读取 readQueues (帧 N-1 的事件)
  
  swap()
  
  帧 N+1:
    ArkTS 写入 writeQueues (原 readQueues)
    C++ 读取 readQueues (帧 N 的事件)
```

### 5.3 FloatBuffer 零拷贝

```typescript
// 问题：跨语言数据传递需要序列化/反序列化，性能差

性能对比：
  传统方式：5-10ms (序列化 + 拷贝 + 反序列化)
  零拷贝：  < 1ms (直接引用)
```

### 5.4 渲染循环优化

```typescript
// GlobalSceneProxy.ets

private startRenderLoop() {
  if (this.renderId !== undefined) return;
  
  // 20ms 间隔 (50 FPS)
  this.renderId = setInterval(() => {
    this.update();
    this.eventQueue.ResetGravity(this.physicalSystem.angle);
  }, 20);
}

update() {
  if (this.physicalSystem.available) {
    // 1. 交换事件队列
    this.eventQueue.swapQueues();
    
    // 2. 更新物理并同步数据
    this.physicalSystem.updateNodeData(
      this.eventQueue.getReadQueues()
    );
    
    // 3. 渲染帧
    this.scene?.renderFrame({ alwaysRender: false });
  }
}

优化点：
  • alwaysRender: false - 仅在场景变化时渲染
  • 20ms 间隔 - 平衡性能和流畅度
  • 条件渲染 - 物理不可用时跳过
```

```typescript
  { x: offsetX, y: offsetY },
  distance,

  fovy: PerspectiveTransform.degToRad(60),

  rotation: parallaxTilt,
```
