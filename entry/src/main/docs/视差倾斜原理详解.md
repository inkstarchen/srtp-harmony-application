# 视差倾斜原理详解

## 一、基本概念

### 什么是视差倾斜？

视差倾斜（Parallax Tilt）是指在透视投影中，由于物体在画面中的位置偏移，而产生的自然倾斜效果。这是透视几何的固有属性，模拟了人眼或相机观察场景时的真实视觉体验。

### 视锥体模型

```
                    Camera (相机位置)
                         ↓
                    ╱─────────╲  ← 视锥体边缘
                   ╱           ╲
                  ╱             ╲
                 ╱               ╲
                ╱   ┌─────────┐   ╲    ← 平面（显示区域）
               ╱    │         │    ╲
              ╱     │  Plane  │     ╲
             ╱      │         │      ╲
            ╱       └─────────┘       ╲
           ╱                           ╲
          ───────────────────────────────
                   ↑
              平面中心点
```

视锥体是一个从相机位置向外延伸的锥形空间，定义了相机能看到的区域。视锥体的形状由以下参数决定：

- **fovy（垂直视场角）**：视锥体在垂直方向的张开角度
- **距离（distance）**：相机到观察平面的距离

## 二、视差倾斜的数学原理

### 2.1 视线方向向量

当相机位于位置 `(0, 0, -distance)`，观察平面上位置为 `(offsetX, offsetY, 0)` 的物体时，视线方向向量可以表示为：

```
视线方向向量 = 物体位置 - 相机位置
            = (offsetX, offsetY, 0) - (0, 0, -distance)
            = (offsetX, offsetY, distance)
```

### 2.2 倾斜角度计算

从相机看向偏离中心的物体，视线方向会产生倾斜。这个倾斜角度可以通过视线方向向量的分量计算：

```
          Camera (0, 0, -d)
                ↓
                │
                │  视线方向 (offsetX, offsetY, d)
                │ ↘
                │  ╲
                │   ╲ θy (Y轴倾斜角)
                │    ╲
────────────────┼─────╲───────────────
                │      ↓
                │   Object
                │  (offsetX, 0, 0)
                │
```

#### X轴倾斜角度（Pitch）

X轴倾斜角度表示从相机看向物体时，在垂直方向上的视角偏移：

```typescript
tiltX = atan2(offsetY, distance)
```

几何意义：
- `offsetY` 是物体在垂直方向偏离中心的距离
- `distance` 是相机到平面的距离
- `atan2` 计算视线方向与水平面的夹角

#### Y轴倾斜角度（Yaw）

Y轴倾斜角度表示从相机看向物体时，在水平方向上的视角偏移：

```typescript
tiltY = -atan2(offsetX, distance)
```

注意：Y轴倾斜方向相反，因为在矩阵变换中，Y轴旋转的正方向是向右倾斜。

### 2.3 示例计算

假设相机距离 `distance = 400px`，物体偏移 `offsetX = 100px, offsetY = 50px`：

```typescript
// X轴倾斜
tiltX = atan2(50, 400) = atan2(50, 400)
     ≈ atan(0.125)
     ≈ 0.124 rad ≈ 7.1°

// Y轴倾斜
tiltY = -atan2(100, 400) = -atan2(100, 400)
     ≈ -atan(0.25)
     ≈ -0.245 rad ≈ -14°
```

## 三、透视效果的强度控制

### 3.1 透视因子（Perspective Factor）

透视因子决定了透视效果的强度，越大则透视变形越明显：

```typescript
perspectiveFactor = tan(fovy / 2) / distance
```

推导过程：
```
              fovy/2
              ↘
               ╲
                ╲ tan(fovy/2) = h / distance
                 ╲
                  ╲
───────────────────╲───────────
                    ↓
              distance

所以：h = distance × tan(fovy/2)
透视因子 = h / distance² = tan(fovy/2) / distance
```

### 3.2 透视增强因子（Perspective Boost）

边缘位置的物体透视效果更强，这是因为在视锥体边缘，光线角度更大：

```typescript
// 计算到中心的距离
distToCenter = sqrt(offsetX² + offsetY²)

// 计算最大偏移距离（平面边缘）
maxOffset = sqrt((planeWidth/2)² + (planeHeight/2)²)

// 透视增强因子：中心为1，边缘约为2
perspectiveBoost = 1 + (distToCenter / maxOffset)
```

```
            透视强度分布示意

         强 ←──────────→ 强
          ╲             ╱
           ╲   中等   ╱
            ╲         ╱
             ╲  最弱  ╱
              ╲     ╱
               ╲   ╱
                ╲ ╱
                 ↓
              中心点
```

## 四、变换矩阵的构建

### 4.1 矩阵组合顺序

完整的透视变换由多个子变换组合而成：

```
最终变换 = 平移 × 透视投影 × 旋转(Rz × Rx × Ry)
```

组合顺序说明：
1. **旋转**：先进行物体自身的旋转
2. **透视投影**：将旋转后的结果进行透视变形
3. **平移**：将结果移动到指定位置

### 4.2 4×4变换矩阵结构

根据ArkUI的矩阵定义（列主序）：

```
│ m00  m01  m02  m03 │  ← 第1列
│ m10  m11  m12  m13 │  ← 第2列
│ m20  m21  m22  m23 │  ← 第3列
│ m30  m31  m32  m33 │  ← 第4列
```

矩阵参数说明：

| 参数 | 作用 | 影响 |
|------|------|------|
| m00 | X轴缩放 | 旋转影响 |
| m01 | 倾斜/旋转 | XY轴旋转或倾斜 |
| m02 | Z方向分量 | XYZ轴旋转 |
| m03 | 透视投影 | 透视投影影响 |
| m10 | 倾斜/旋转 | XYZ轴旋转或倾斜 |
| m11 | Y轴缩放 | 旋转影响 |
| m12 | Z方向分量 | XYZ轴旋转 |
| m13 | 透视投影 | 透视投影影响 |
| m20 | Z方向分量 | XYZ轴旋转 |
| m21 | Z方向分量 | XYZ轴旋转 |
| m22 | Z轴缩放 | 旋转影响 |
| m23 | 透视投影 | 透视投影影响 |
| m30 | X轴平移 | 位置偏移 |
| m31 | Y轴平移 | 位置偏移 |
| m32 | Z轴平移 | 深度偏移 |
| m33 | 齐次坐标 | 透视投影生效 |

### 4.3 矩阵计算代码

```typescript
// 组合旋转角度 = 视差倾斜 + 组件自身旋转
const combinedRotX = rotation.x + parallaxTilt.x;
const combinedRotY = rotation.y + parallaxTilt.y;
const combinedRotZ = rotation.z || 0;

// 三角函数值
const cosX = Math.cos(combinedRotX);
const sinX = Math.sin(combinedRotX);
const cosY = Math.cos(combinedRotY);
const sinY = Math.sin(combinedRotY);
const cosZ = Math.cos(combinedRotZ);
const sinZ = Math.sin(combinedRotZ);

// 透视因子（带增强）
const p = basePerspectiveFactor * perspectiveBoost;

// 计算矩阵元素（列主序）
const m00 = cosY * cosZ + sinX * sinY * sinZ;
const m01 = -cosX * sinZ;
const m02 = sinY * cosZ - sinX * cosY * sinZ;
const m03 = p * m02;  // 透视分量

const m10 = cosY * sinZ - sinX * sinY * cosZ;
const m11 = cosX * cosZ;
const m12 = sinY * sinZ + sinX * cosY * cosZ;
const m13 = p * m12;  // 透视分量

const m20 = -cosX * sinY;
const m21 = sinX;
const m22 = cosX * cosY;
const m23 = p * m22;  // 透视分量

// 平移分量
const m30 = offset.x;
const m31 = offset.y;
const m32 = -cameraDistance;  // 深度偏移
const m33 = 1;
```

## 五、实际应用场景

### 5.1 卡片网格布局

当多个卡片在屏幕上呈网格分布时，每个卡片都应该有不同的视差倾斜：

```
┌────────────────────────────────────┐
│  ┌───┐    ┌───┐    ┌───┐    ┌───┐  │
│  │ ↗ │    │ ↗ │    │ ↗ │    │ ↗ │  │  ← 上排：向上倾斜
│  └───┘    └───┘    └───┘    └───┘  │
│                                    │
│  ┌───┐    ┌───┐    ┌───┐    ┌───┐  │
│  │ → │    │ 0 │    │ ← │    │ ← │  │  ← 中排：水平倾斜
│  └───┘    └───┘    └───┘    └───┘  │     中心最小
│                                    │
│  ┌───┐    ┌───┐    ┌───┐    ┌───┐  │
│  │ ↘ │    │ ↘ │    │ ↘ │    │ ↘ │  │  ← 下排：向下倾斜
│  └───┘    └───┘    └───┘    └───┘  │
└────────────────────────────────────┘
          ↙              ↘
    左侧向左倾斜      右侧向右倾斜
```

代码示例：
```typescript
// 网格布局（带视差）
for (let row = 0; row < 3; row++) {
  for (let col = 0; col < 4; col++) {
    // 网格位置 (-1 到 1)
    const gridX = (col - 1.5) / 1.5;
    const gridY = (row - 1) / 1;

    const matrix = PerspectiveTransform.gridCardWithParallax(
      gridX, gridY,
      planeWidth, planeHeight,
      60,  // fovy
      400  // distance
    );

    // 应用矩阵到卡片
    card.transform3D = matrix4.init(matrix);
  }
}
```

### 5.2 单卡片偏移效果

单个卡片在屏幕上的位置偏移：

```typescript
// 卡片在屏幕右上方，距离中心 (-100, 50)
const matrix = PerspectiveTransform.calculateTransformMatrix({
  fovy: PerspectiveTransform.degToRad(60),
  cameraDistance: 400,
  rotation: { x: 0, y: 0, z: 0 },  // 无额外旋转
  offset: { x: -100, y: 50 },       // 偏移位置
  planeSize: { width: 800, height: 600 }
});

// 结果：
// - 卡片会自动向右上倾斜（视差效果）
// - 无需手动设置旋转角度
```

### 5.3 组合旋转效果

组件自身旋转叠加视差倾斜：

```typescript
// 卡片自身有旋转，同时位置偏移产生视差
const matrix = PerspectiveTransform.calculateTransformMatrix({
  fovy: PerspectiveTransform.degToRad(60),
  cameraDistance: 400,
  rotation: { x: 10, y: 20, z: 0 },  // 组件自身旋转10°、20°
  offset: { x: -100, y: 50 },         // 偏移位置
  planeSize: { width: 800, height: 600 }
});

// 实际旋转 = 视差倾斜 + 自身旋转
// tiltX ≈ 7°, tiltY ≈ -14°
// 实际: X轴旋转 ≈ 17°, Y轴旋转 ≈ 6°
```

## 六、参数调节指南

### 6.1 fovy（视场角）

| fovy值 | 效果 | 适用场景 |
|--------|------|----------|
| 30° | 微弱透视 | 平面化UI，轻微3D感 |
| 60° | 中等透视 | 标准卡片效果，推荐值 |
| 90° | 强透视 | 戏剧性效果，游戏风格 |
| 120° | 极强透视 | 鱼眼效果，特殊艺术 |

### 6.2 distance（相机距离）

| 距离 | 效果 | 建议 |
|------|------|------|
| 平面高度/2 | 最佳默认值 | 能完整看到平面 |
| 更小距离 | 透视更强 | 注意可能裁切边缘 |
| 更大距离 | 透视更弱 | 接近平面效果 |

### 6.3 视差效果对比

```
距离 = 400px 时：

偏移量        视差倾斜角度
(0, 0)        (0°, 0°)      ← 中心，无倾斜
(50, 0)       (0°, -7°)     ← 水平偏移
(0, 50)       (7°, 0°)      ← 垂直偏移
(100, 100)    (14°, -14°)   ← 对角偏移
(200, 200)    (27°, -27°)   ← 大偏移，强倾斜
```

## 七、常见问题

### Q1: 为什么边缘的卡片看起来"变形"？

这是透视投影的正常效果。在真实世界中，从特定角度看平面，边缘的物体确实会有更大的变形。视差倾斜正是模拟这种真实效果。

### Q2: 如何让所有卡片看起来"一致"？

如果希望所有卡片保持相同角度，可以：
1. 禁用视差效果
2. 使用 `calculateSimpleTransform` 方法
3. 或者增大相机距离，减小透视强度

```typescript
// 禁用视差，所有卡片角度一致
const matrix = PerspectiveTransform.calculateSimpleTransform(
  fovy, distance, rotateX, rotateY, offsetX, offsetY
);
```

### Q3: 视差倾斜和组件旋转如何叠加？

两者是简单相加：

```
实际旋转角度 = 视差倾斜角度 + 组件自身旋转角度
```

如果组件需要保持"正视"相机，可以设置组件自身旋转为视差倾斜的相反值。

## 八、总结

视差倾斜是透视几何的自然结果，通过计算视线方向的角度偏移，自动为不同位置的物体产生相应的倾斜效果。

**核心公式：**
```typescript
tiltX = atan2(offsetY, distance)    // X轴倾斜（垂直偏移）
tiltY = -atan2(offsetX, distance)   // Y轴倾斜（水平偏移）
perspectiveFactor = tan(fovy/2) / distance
```

**效果：**
- 偏移越大 → 倾斜越大
- 距离越近 → 透视越强
- fovy越大 → 透视越强

这种效果让2D平面布局产生自然的3D视觉体验，特别适合卡片网格、照片墙等场景。
