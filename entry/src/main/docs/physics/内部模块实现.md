## 2. SoA 内存布局设计

### 2.1 设计理念

物理系统采用 **Structure of Arrays (SoA)** 布局，而非传统的 Array of Structures (AoS)：

**AoS 布局（传统）**：
```cpp
struct Body {
    float posX, posY, posZ;
    float velX, velY, velZ;
    float rotX, rotY, rotZ, rotW;
    // ...
};
Body bodies[128];
```

**SoA 布局（当前）**：
```cpp
float* pos_x = new float[128];
float* pos_y = new float[128];
float* pos_z = new float[128];
float* vel_x = new float[128];
// ...
```

### 2.2 SoA 优势

| 优势 | 说明 |
|------|------|
| 缓存友好 | 同一类型数据连续存储，SIMD 向量化效率高 |
| 批量处理 | 可以一次处理所有节点的单一属性 |
| 零拷贝 | FloatBuffer 直接暴露给 ArkTS，无需数据转换 |
| 内存效率 | 按需读取，不需要的属性不会加载到缓存 |

### 2.3 内存分配流程

```cpp
PhysicsSystem::PhysicsSystem(size_t cap) {
    // 1. 容量对齐（64 字节边界）
    capacity = alignCapacity(cap);
    
    // 2. 计算总内存需求
    const size_t floatCount = 
        3   // position (x, y, z)
        + 4 // rotation (x, y, z, w)
        + 3 // scale (x, y, z)
        + 3 // velocity (x, y, z)
        + 3 // angular velocity (x, y, z)
        + 3 // force (x, y, z)
        + 3 // torque (x, y, z)
        + 3 // impulse (x, y, z)
        + 3 // inverse inertia (xx, yy, zz)
        + 3 // extent (x, y, z)
        + 3 // material (invMass, restitution, friction)
        + 4 // rest rotation (x, y, z, w)
        + 2 // rotation spring (K, D)
        = 40 floats per node;
    
    size_t bytes = capacity * (
        floatCount * sizeof(float) +
        sizeof(int32_t) +   // shapeType
        sizeof(uint8_t) +   // isStatic
        sizeof(uint8_t)     // canRotate
    );
    
    // 3. 一次性分配大块内存
    base_ptr = malloc(bytes);
    
    // 4. 使用游标指针分割内存块
    uint8_t* cursor = static_cast<uint8_t*>(base_ptr);
    
    ALLOC_FLOAT(pos_x)
    ALLOC_FLOAT(pos_y)
    ALLOC_FLOAT(pos_z)
    ALLOC_FLOAT(rot_x)
    // ... 继续分配所有数组
    
    // 5. 清零内存
    std::memset(base_ptr, 0, bytes);
}
```

### 2.5 空闲列表管理

```cpp
std::vector<uint32_t> free_list;

// 节点分配
uint32_t PhysicsSystem::newNode() {
    uint32_t id;
    if (!free_list.empty()) {
        // 复用已删除节点的空位
        id = free_list.back();
        free_list.pop_back();
    } else {
        // 分配新 ID
        id = count++;
        assert(id < capacity && "Exceed capacity");
    }
    return id;
}

// 场景重置
void PhysicsSystem::ReleaseScene() {
    count = 0;
    free_list.clear();
    // 重新填充空闲列表
    for (int32_t i = capacity - 1; i >= 0; i--) {
        free_list.push_back(static_cast<uint32_t>(i));
    }
    // 清零内存
    std::memset(base_ptr, 0, bytes);
}
```

## 3. 物理模拟流水线

### 3.1 步进流程

```cpp
void PhysicsSystem::step(float dt) {
    // 自适应子步长计算
    int subSteps = computeSubSteps(dt);
    float subDt = dt / subSteps;

    for (int i = 0; i < subSteps; ++i) {
        // === 阶段 1: 碰撞检测 ===
        detectCollisions();        // 检测潜在碰撞对
        
        // === 阶段 2: 构建接触点 ===
        buildContacts();           // 生成接触点数据
        
        // === 阶段 3: 碰撞解算 ===
        solveContacts();           // 应用冲量求解
        
        // === 阶段 3.5: 旋转弹簧 ===
        applyRotationSprings(subDt); // 应用旋转恢复力矩
        
        // === 阶段 4: 速度积分 ===
        integrateVelocity(subDt);   // 更新线速度和角速度
        
        // === 阶段 5: 速度限制 ===
        clampVelocity(subDt);       // 防止穿透的速度钳制
        
        // === 阶段 6: 位置修正 ===
        positionalCorrection();     // 穿透位置修正
        
        // === 阶段 7: 位置积分 ===
        integratePosition(subDt);   // 更新位置和旋转
    }
}
```

### 3.2 流水线阶段详解

#### 阶段 1: detectCollisions()

**功能**：遍历所有节点对，执行粗粒度碰撞检测

**算法**：
```cpp
void PhysicsSystem::detectCollisions() {
    possiblePairs.clear();
    
    // O(n²) 遍历所有节点对
    for (uint32_t i = 0; i < count; ++i) {
        for (uint32_t j = i + 1; j < count; ++j) {
            // 跳过两个静态物体
            if (isStatic[i] && isStatic[j]) continue;
            
            // 根据形状类型调用对应的碰撞检测函数
            if (testCollision(i, j)) {
                possiblePairs.emplace_back(i, j);
            }
        }
    }
}
```

**性能优化点**：
- 静态物体之间不检测
- 未来可引入空间分割（Grid/Octree）降低复杂度

#### 阶段 2: buildContacts()

**功能**：为每个碰撞对生成详细的接触点数据

**Contact 结构体**：
```cpp
struct Contact {

    Vector3 normal;             // 碰撞法线（指向 A）
```

**代码**：
```cpp
void PhysicsSystem::buildContacts() {
    contact.clear();
    
    for (auto& pair : possiblePairs) {
        uint32_t idA = pair.first;
        uint32_t idB = pair.second;
        
        Contact c;
        c.a = idA;
        c.b = idB;
        
        // 根据形状类型分派到对应的接触点生成函数
        ContactDispatch::dispatch(*this, idA, idB, c);
        
        contact.emplace_back(c);
    }
}
```

#### 阶段 4: integrateVelocity()

**功能**：根据力和重力更新速度

**代码**：
```cpp
void PhysicsSystem::integrateVelocity(float dt) {
    for (uint32_t i = 0; i < count; ++i) {
        if (isStatic[i]) {
            vel_x[i] = vel_y[i] = vel_z[i] = 0.0f;
            if (!canRotate[i]) {
                angVel_x[i] = angVel_y[i] = angVel_z[i] = 0.0f;
                continue;
            }
        }

        // 线性速度积分：v += (F/m + g) * dt
        vel_x[i] += (force_x[i] * invMass[i] + gravity.x) * dt;
        vel_y[i] += (force_y[i] * invMass[i] + gravity.y) * dt;
        vel_z[i] += (force_z[i] * invMass[i] + gravity.z) * dt;

        // 角速度积分：ω += τ/I * dt
        angVel_x[i] += torque_x[i] * invInertial_xx[i] * dt;
        angVel_y[i] += torque_y[i] * invInertial_yy[i] * dt;
        angVel_z[i] += torque_z[i] * invInertial_zz[i] * dt;

        // 指数衰减阻尼（帧率无关）
        const float LIN_DAMP_COEFF = 0.02f;
        const float ANG_DAMP_COEFF = 0.05f;
        float linDamp = expf(-LIN_DAMP_COEFF * dt);
        float angDamp = expf(-ANG_DAMP_COEFF * dt);
        vel_x[i] *= linDamp; vel_y[i] *= linDamp; vel_z[i] *= linDamp;
        angVel_x[i] *= angDamp; angVel_y[i] *= angDamp; angVel_z[i] *= angDamp;

        // NaN/Inf 防护
        if (std::isnan(vel_x[i]) || std::isinf(vel_x[i])) {
            vel_x[i] = vel_y[i] = vel_z[i] = 0.0f;
        }
    }

    // 清除所有力
    clearForceAll();
}
```

#### 阶段 5: clampVelocity()

**功能**：限制速度大小，防止快速物体穿透

**算法**：
```cpp
void PhysicsSystem::clampVelocity(float dt) {
    const float SAFETY_FACTOR = 0.4f;
    
    for (uint32_t i = 0; i < count; ++i) {
        if (isStatic[i]) continue;
        
        float speed = sqrtf(vel_x[i]^2 + vel_y[i]^2 + vel_z[i]^2);
        if (speed < 1e-6f) continue;
        
        // 最大允许位移 = 最小尺寸 * 安全系数
        float minExtent = min(extent_x[i], extent_y[i], extent_z[i]);
        float maxMove = minExtent * SAFETY_FACTOR;
        float maxSpeed = maxMove / dt;
        
        // 钳制速度
        if (speed > maxSpeed) {
            float scale = maxSpeed / speed;
            vel_x[i] *= scale;
            vel_y[i] *= scale;
            vel_z[i] *= scale;
        }
    }
}
```

#### 阶段 6: positionalCorrection()

**功能**：修正已发生的穿透

**算法**：
```cpp
void PhysicsSystem::positionalCorrection() {
    const float k_slop = 0.01f;  // 容差（防止 jitter）
    const float percent = 0.8f;  // 修正比例
    
    for (const auto& c : contact) {
        float penetration = max(c.penetration - k_slop, 0.0f);
        if (penetration <= 0.0f) continue;
        
        // 按质量比例分配修正量
        float invMassA = isStatic[c.a] ? 0.0f : invMass[c.a];
        float invMassB = isStatic[c.b] ? 0.0f : invMass[c.b];
        float invMassSum = invMassA + invMassB;
        if (invMassSum == 0.0f) continue;
        
        float correction = (penetration / invMassSum) * percent;
        
        // 应用位置修正
        if (!isStatic[c.a]) {
            pos_x[c.a] += c.normal.x * correction * invMassA;
            pos_y[c.a] += c.normal.y * correction * invMassA;
            pos_z[c.a] += c.normal.z * correction * invMassA;
        }
        if (!isStatic[c.b]) {
            pos_x[c.b] -= c.normal.x * correction * invMassB;
            pos_y[c.b] -= c.normal.y * correction * invMassB;
            pos_z[c.b] -= c.normal.z * correction * invMassB;
        }
    }
}
```

#### 阶段 7: integratePosition()

**功能**：根据速度更新位置和旋转

**代码**：
```cpp
void PhysicsSystem::integratePosition(float dt) {
    for (uint32_t i = 0; i < count; ++i) {
        bool isStaticObj = isStatic[i];
        bool canRot = canRotate[i];
        
        if (isStaticObj && !canRot) continue;
        
        // 更新位置（静态物体不更新）
        if (!isStaticObj) {
            pos_x[i] += vel_x[i] * dt;
            pos_y[i] += vel_y[i] * dt;
            pos_z[i] += vel_z[i] * dt;
        }
        
        // 更新旋转（四元数积分）
        float wx = angVel_x[i];
        float wy = angVel_y[i];
        float wz = angVel_z[i];
        
        float qx = rot_x[i], qy = rot_y[i], qz = rot_z[i], qw = rot_w[i];
        float half_dt = 0.5f * dt;
        
        // 四元数导数：dq/dt = 0.5 * ω ⊗ q
        float nx = half_dt * (wx*qw + wy*qz - wz*qy);
        float ny = half_dt * (-wx*qz + wy*qw + wz*qx);
        float nz = half_dt * (wx*qy - wy*qx + wz*qw);
        float nw = half_dt * (-wx*qx - wy*qy - wz*qz);
        
        qx += nx; qy += ny; qz += nz; qw += nw;
        
        // 归一化四元数
        float norm = sqrt(qx^2 + qy^2 + qz^2 + qw^2);
        rot_x[i] = qx / norm;
        rot_y[i] = qy / norm;
        rot_z[i] = qz / norm;
        rot_w[i] = qw / norm;
    }
}
```

## 4. 碰撞检测算法实现

### 4.1 碰撞分发器

```cpp
// collision.h
class CollisionDispatch {
public:
    static CollisionFunc table[SHAPE_COUNT][SHAPE_COUNT];
    
    static bool dispatch(const PhysicsSystem& physics, uint32_t A, uint32_t B) {
        uint32_t shapeA = physics.shapeType[A];
        uint32_t shapeB = physics.shapeType[B];
        return table[shapeA][shapeB](physics, A, B);
    }
};
```

### 4.2 球体-球体碰撞

```cpp
bool testSphereSphere(const PhysicsSystem& physics, uint32_t A, uint32_t B) {
    // 计算中心距离
    float dx = physics.pos_x[A] - physics.pos_x[B];
    float dy = physics.pos_y[A] - physics.pos_y[B];
    float dz = physics.pos_z[A] - physics.pos_z[B];
    float distSq = dx*dx + dy*dy + dz*dz;
    
    // 半径和
    float r1 = physics.extent_x[A];
    float r2 = physics.extent_x[B];
    float radiusSum = r1 + r2;
    
    // 碰撞条件：距离 < 半径和
    return distSq < radiusSum * radiusSum;
}
```

### 4.3 OBB-OBB 碰撞（SAT 分离轴定理）

```cpp
bool testBoxBox(const PhysicsSystem& physics, uint32_t A, uint32_t B) {
    // 获取两个 OBB 的位置、旋转、半长轴
    Vector3 posA(physics.pos_x[A], physics.pos_y[A], physics.pos_z[A]);
    Vector3 posB(physics.pos_x[B], physics.pos_y[B], physics.pos_z[B]);
    
    Quaternion rotA(physics.rot_x[A], physics.rot_y[A], physics.rot_z[A], physics.rot_w[A]);
    Quaternion rotB(physics.rot_x[B], physics.rot_y[B], physics.rot_z[B], physics.rot_w[B]);
    
    Vector3 extentA(physics.extent_x[A], physics.extent_y[A], physics.extent_z[A]);
    Vector3 extentB(physics.extent_x[B], physics.extent_y[B], physics.extent_z[B]);
    
    // 使用 SAT 检测 15 个分离轴
    return testOBBOBB(posA, rotA, extentA, posB, rotB, extentB);
}
```

**SAT 算法核心**：
```cpp
bool testOBBOBB(...) {
    // 1. 获取两个 OBB 的局部轴
    Vector3 axisA[3], axisB[3];
    getOBBAxis(rotA, axisA);
    getOBBAxis(rotB, axisB);
    
    // 2. 测试 15 个分离轴
    //    - 3 个 A 的轴
    for (int i = 0; i < 3; i++) {
        if (!projectAndTest(axisA[i], ...)) return false;
    }
    
    //    - 3 个 B 的轴
    for (int i = 0; i < 3; i++) {
        if (!projectAndTest(axisB[i], ...)) return false;
    }
    
    //    - 9 个叉积轴
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            Vector3 crossAxis = cross(axisA[i], axisB[j]);
            if (crossAxis.lengthSq() < 1e-6f) continue; // 平行轴
            if (!projectAndTest(crossAxis, ...)) return false;
        }
    }
    
    // 所有轴都重叠 → 碰撞
    return true;
}
```

```cpp
// 从四元数提取旋转矩阵的三个轴
inline void getOBBAxis(const Quaternion& rot, Vector3 axis[3]) {
    float xx = rot.x * rot.x;
    float yy = rot.y * rot.y;
    float zz = rot.z * rot.z;
    float xy = rot.x * rot.y;
    float xz = rot.x * rot.z;
    float yz = rot.y * rot.z;
    float wx = rot.w * rot.x;
    float wy = rot.w * rot.y;
    float wz = rot.w * rot.z;
    
    // X 轴
    axis[0] = Vector3(
        1.0f - 2.0f * (yy + zz),
        2.0f * (xy + wz),
        2.0f * (xz - wy)
    );
    
    // Y 轴
    axis[1] = Vector3(
        2.0f * (xy - wz),
        1.0f - 2.0f * (xx + zz),
        2.0f * (yz + wx)
    );
    
    // Z 轴
    axis[2] = Vector3(
        2.0f * (xz + wy),
        2.0f * (yz - wx),
        1.0f - 2.0f * (xx + yy)
    );
}
```

## 5. 碰撞响应机制

### 5.1 冲量法求解

**核心思想**：在接触点施加冲量，使碰撞物体分离并产生合理的反弹效果

### 5.2 算法流程

```cpp
void PhysicsSystem::solveContacts() {
    for (const auto& c : contact) {
        uint32_t a = c.a;
        uint32_t b = c.b;
        
        // === 步骤 1: 计算相对速度 ===
        float nx = c.normal.x, ny = c.normal.y, nz = c.normal.z;
        
        // 接触点相对于质心的位置
        float rax = c.point.x - pos_x[a];
        float ray = c.point.y - pos_y[a];
        float raz = c.point.z - pos_z[a];
        
        float rbx = c.point.x - pos_x[b];
        float rby = c.point.y - pos_y[b];
        float rbz = c.point.z - pos_z[b];
        
        // 角速度贡献：v_point = v_center + ω × r
        float cross_ax = angVel_y[a]*raz - angVel_z[a]*ray;
        float cross_ay = angVel_z[a]*rax - angVel_x[a]*raz;
        float cross_az = angVel_x[a]*ray - angVel_y[a]*rax;
        
        float cross_bx = angVel_y[b]*rbz - angVel_z[b]*rby;
        float cross_by = angVel_z[b]*rbx - angVel_x[b]*rbz;
        float cross_bz = angVel_x[b]*rby - angVel_y[b]*rbx;
        
        // 相对速度
        float va_rel_x = (vel_x[a] + cross_ax) - (vel_x[b] + cross_bx);
        float va_rel_y = (vel_y[a] + cross_ay) - (vel_y[b] + cross_by);
        float va_rel_z = (vel_z[a] + cross_az) - (vel_z[b] + cross_bz);
        
        // 法向相对速度
        float relVelAlongNormal = va_rel_x*nx + va_rel_y*ny + va_rel_z*nz;
        
        // 如果正在分离，跳过
        if (relVelAlongNormal > 0.0f) continue;
        
        // === 步骤 2: 计算法向冲量 ===
        float e = min(restitution[a], restitution[b]);
        float invMassA = isStatic[a] ? 0.0f : invMass[a];
        float invMassB = isStatic[b] ? 0.0f : invMass[b];
        
        // 惯性张量贡献（简化为对角矩阵）
        float invInertiaA_xx = isStatic[a] ? 0.0f : invInertial_xx[a];
        float invInertiaA_yy = isStatic[a] ? 0.0f : invInertial_yy[a];
        float invInertiaA_zz = isStatic[a] ? 0.0f : invInertial_zz[a];
        
        float invInertiaB_xx = isStatic[b] ? 0.0f : invInertial_xx[b];
        float invInertiaB_yy = isStatic[b] ? 0.0f : invInertial_yy[b];
        float invInertiaB_zz = isStatic[b] ? 0.0f : invInertial_zz[b];
        
        // r × n
        float rn_ax = ray*nz - raz*ny;
        float rn_ay = raz*nx - rax*nz;
        float rn_az = rax*ny - ray*nx;
        
        float rn_bx = rby*nz - rbz*ny;
        float rn_by = rbz*nx - rbx*nz;
        float rn_bz = rbx*ny - rby*nx;
        
        // 角动量贡献
        float angularTerm_a = invInertiaA_xx*rn_ax^2 + invInertiaA_yy*rn_ay^2 + invInertiaA_zz*rn_az^2;
        float angularTerm_b = invInertiaB_xx*rn_bx^2 + invInertiaB_yy*rn_by^2 + invInertiaB_zz*rn_bz^2;
        
        // 冲量公式
        float j = -(1.0f + e) * relVelAlongNormal / (invMassA + invMassB + angularTerm_a + angularTerm_b);
        
        // 防止冲量过大
        const float MAX_IMPULSE = 1e6f;
        if (abs(j) > MAX_IMPULSE) {
            j = (j > 0 ? MAX_IMPULSE : -MAX_IMPULSE);
        }
        
        // === 步骤 3: 计算摩擦冲量 ===
        float tx = va_rel_x - relVelAlongNormal * nx;
        float ty = va_rel_y - relVelAlongNormal * ny;
        float tz = va_rel_z - relVelAlongNormal * nz;
        float tLen = sqrt(tx^2 + ty^2 + tz^2);
        
        float frictionImpulse = 0.0f;
        float frictionCoeff = (friction[a] + friction[b]) * 0.5f;
        
        if (tLen > 1e-6f) {
            // 切向单位向量
            tx /= tLen; ty /= tLen; tz /= tLen;
            
            // 切向相对速度
            float relVelTangent = va_rel_x*tx + va_rel_y*ty + va_rel_z*tz;
            
            // 切向冲量（类似法向计算）
            float jt = -relVelTangent / invMassSum_t;
            
            // Coulomb 摩擦定律
            float maxFriction = abs(j) * frictionCoeff;
            frictionImpulse = clamp(jt, -maxFriction, maxFriction);
        }
        
        // === 步骤 4: 应用冲量 ===
        float impulseX = j * nx + frictionImpulse * tx;
        float impulseY = j * ny + frictionImpulse * ty;
        float impulseZ = j * nz + frictionImpulse * tz;
        
        // 物体 A
        if (!isStatic[a]) {
            vel_x[a] += impulseX * invMassA;
            vel_y[a] += impulseY * invMassA;
            vel_z[a] += impulseZ * invMassA;
            
            // 角冲量：Δω = I^-1 * (r × impulse)
            angVel_x[a] += (ray*impulseZ - raz*impulseY) * invInertiaA_xx;
            angVel_y[a] += (raz*impulseX - rax*impulseZ) * invInertiaA_yy;
            angVel_z[a] += (rax*impulseY - ray*impulseX) * invInertiaA_zz;
        }
        
        // 物体 B（反向冲量）
        if (!isStatic[b]) {
            vel_x[b] -= impulseX * invMassB;
            vel_y[b] -= impulseY * invMassB;
            vel_z[b] -= impulseZ * invMassB;
            
            angVel_x[b] -= (rby*impulseZ - rbz*impulseY) * invInertiaB_xx;
            angVel_y[b] -= (rbz*impulseX - rbx*impulseZ) * invInertiaB_yy;
            angVel_z[b] -= (rbx*impulseY - rby*impulseX) * invInertiaB_zz;
        }
    }
}
```

### 5.3 物理公式推导

**法向冲量公式**：

```
j = -(1 + e) * v_rel · n
    ──────────────────────
    1/m_A + 1/m_B + n·(I_A^-1*(r_A×n))×r_A + n·(I_B^-1*(r_B×n))×r_B

其中：
  e = 恢复系数
  v_rel = 相对速度
  n = 碰撞法线
  m = 质量
  I = 惯性张量
  r = 接触点到质心的向量
```

**Coulomb 摩擦定律**：

```
|j_t| ≤ |j_n| * μ

其中：
  j_t = 切向冲量
  j_n = 法向冲量
  μ = 摩擦系数
```

### 6.1 模块位置

### 6.2 射线-AABB 检测（slab 方法）

```cpp
inline bool raycastAABB(
    const Vector3& origin,    // 射线起点
    const Vector3& dir,       // 射线方向
    const Vector3& center,    // AABB 中心
    const Vector3& halfExtent,// 半长轴
    double& tmin,             // 最近交点
    double& tmax              // 最远交点
) {
    tmin = 0.0;
    tmax = FLT_MAX;
    
    Vector3 bmin = center - halfExtent;
    Vector3 bmax = center + halfExtent;
    
    // 对每个轴计算射线与平面的交点
    for (int i = 0; i < 3; i++) {
        double o = origin[i];
        double d = dir[i];
        
        if (abs(d) < 1e-8) {
            // 射线平行于平面
            if (o < bmin[i] || o > bmax[i]) return false;
        } else {
            double t1 = (bmin[i] - o) / d;
            double t2 = (bmax[i] - o) / d;
            
            if (t1 > t2) swap(t1, t2);
            
            tmin = max(tmin, t1);
            tmax = min(tmax, t2);
            
            if (tmin > tmax) return false;
        }
    }
    
    return true;
}
```

### 6.3 射线-OBB 检测

**思路**：将射线变换到 OBB 局部空间，然后使用 slab 方法

```cpp
inline bool raycastOBB(
    const Vector3& origin,
    const Vector3& dir,
    const Vector3& center,
    const Quaternion& rotation,
    const Vector3& halfExtent,
    double& t
) {
    // 1. 获取 OBB 的局部轴
    Vector3 axis[3];
    getOBBAxis(rotation, axis);
    
    // 2. 将射线变换到 OBB 局部空间
    Vector3 p = origin - center;
    Vector3 localOrigin(dot(p, axis[0]), dot(p, axis[1]), dot(p, axis[2]));
    Vector3 localDir(dot(dir, axis[0]), dot(dir, axis[1]), dot(dir, axis[2]));
    
    // 3. 在局部空间执行 slab 测试
    double tmin = 0.0, tmax = FLT_MAX;
    
    for (int i = 0; i < 3; i++) {
        double o = localOrigin[i];
        double d = localDir[i];
        float e = halfExtent[i];
        
        if (abs(d) < 1e-8) {
            if (o < -e || o > e) return false;
        } else {
            double t1 = (-e - o) / d;
            double t2 = (e - o) / d;
            if (t1 > t2) swap(t1, t2);
            tmin = max(tmin, t1);
            tmax = min(tmax, t2);
            if (tmin > tmax) return false;
        }
    }
    
    t = tmin;
    return tmin >= 0;
}
```

### 6.4 射线-球体检测

```cpp
inline bool raycastSphere(
    const Vector3& origin,
    const Vector3& dir,
    const Vector3& center,
    float radius,
    double& t
) {
    Vector3 oc = origin - center;
    double a = dir.dot(dir);
    double b = 2.0 * oc.dot(dir);
    double c = oc.dot(oc) - radius * radius;
    
    double discriminant = b * b - 4.0 * a * c;
    if (discriminant < 0) return false;
    
    double sqrtDisc = sqrt(discriminant);
    double t0 = (-b - sqrtDisc) / (2.0 * a);
    double t1 = (-b + sqrtDisc) / (2.0 * a);
    
    if (t0 > 0) { t = t0; return true; }
    if (t1 > 0) { t = t1; return true; }
    return false;
}
```

## 7. 旋转弹簧系统

### 7.1 功能说明

为布局系统中的物体提供旋转恢复力，扰动后自动回到初始旋转状态

### 7.2 物理模型

```
T_spring = K * error - D * ω

其中：
  T_spring = 弹簧力矩
  K = 刚度系数
  error = 旋转误差向量
  D = 阻尼系数
  ω = 角速度
```

### 7.3 实现代码

```cpp
void PhysicsSystem::applyRotationSprings(float dt) {
    // 仅在布局系统启用时生效
    if (layoutManager == nullptr) return;
    
    for (uint32_t i = 0; i < count; ++i) {
        // 只对允许旋转的物体生效
        if (!canRotate[i]) continue;
        
        // 确保惯性张量已计算
        if (invInertial_xx[i] < 1e-6f) {
            updateInvInertia(i);
        }
        
        // 当前旋转和目标旋转
        Quaternion q_curr(rot_x[i], rot_y[i], rot_z[i], rot_w[i]);
        Quaternion q_rest(restRot_x[i], restRot_y[i], restRot_z[i], restRot_w[i]);
        
        // 计算误差四元数：deltaQ = q_rest * q_curr.conjugate()
        Quaternion q_conj(-rot_x[i], -rot_y[i], -rot_z[i], rot_w[i]);
        Quaternion deltaQ = q_rest * q_conj;
        
        // 误差向量（虚部）
        Vector3 error(deltaQ.x, deltaQ.y, deltaQ.z);
        
        // 弹簧力矩
        float k = rotSpringK[i];
        float d = rotSpringD[i];
        
        float tx = 2.0f * k * error.x - d * angVel_x[i];
        float ty = 2.0f * k * error.y - d * angVel_y[i];
        float tz = 2.0f * k * error.z - d * angVel_z[i];
        
        // 累加到当前力矩
        torque_x[i] += tx;
        torque_y[i] += ty;
        torque_z[i] += tz;
    }
}
```

## 9. 自适应子步长与防穿透

### 9.1 问题背景

快速移动的物体可能在一帧内穿过障碍物（隧道效应）

### 9.2 解决方案：自适应子步长

```cpp
int PhysicsSystem::computeSubSteps(float dt) {
    const int MAX_SUB_STEPS = 8;
    const float SAFETY_FACTOR = 0.4f;
    
    int maxNeeded = 1;
    
    for (uint32_t i = 0; i < count; ++i) {
        if (isStatic[i]) continue;
        
        // 计算速度
        float speed = sqrt(vel_x[i]^2 + vel_y[i]^2 + vel_z[i]^2);
        if (speed < 1e-6f) continue;
        
        // 物体最小尺寸
        float minExtent = min(extent_x[i], extent_y[i], extent_z[i]);
        
        // 最大允许位移
        float maxMove = minExtent * SAFETY_FACTOR;
        if (maxMove < 1e-6f) maxMove = 0.01f;
        
        // 需要的子步数
        float move = speed * dt;
        int needed = ceil(move / maxMove);
        
        maxNeeded = max(maxNeeded, needed);
    }
    
    return min(maxNeeded, MAX_SUB_STEPS);
}
```

### 9.3 速度钳制

```cpp
void PhysicsSystem::clampVelocity(float dt) {

    }
}
```

### 9.4 位置修正

即使有子步长和速度钳制，仍可能发生轻微穿透。位置修正阶段会强制分离重叠物体：

```cpp
void PhysicsSystem::positionalCorrection() {
    const float k_slop = 0.01f;  // 容差（防止抖动）
    const float percent = 0.8f;  // 修正比例
    
    for (const auto& c : contact) {
        float penetration = max(c.penetration - k_slop, 0.0f);
        if (penetration <= 0.0f) continue;
        
        // 按质量比例分配修正
        float invMassA = isStatic[c.a] ? 0.0f : invMass[c.a];
        float invMassB = isStatic[c.b] ? 0.0f : invMass[c.b];
        float invMassSum = invMassA + invMassB;
        if (invMassSum == 0.0f) continue;
        
        float correction = (penetration / invMassSum) * percent;
        
        // 应用修正
        if (!isStatic[c.a]) {
            pos_x[c.a] += c.normal.x * correction * invMassA;
            pos_y[c.a] += c.normal.y * correction * invMassA;
            pos_z[c.a] += c.normal.z * correction * invMassA;
        }
        if (!isStatic[c.b]) {
            pos_x[c.b] -= c.normal.x * correction * invMassB;
            pos_y[c.b] -= c.normal.y * correction * invMassB;
            pos_z[c.b] -= c.normal.z * correction * invMassB;
        }
    }
}
```

```cpp
    size_t argc = 2;

    obj->clearEventResults();
    obj->processEventQueueFromJS(eventQueue);
    
    // 执行物理步进
    obj->step(static_cast<float>(d));
    
    // 更新 FloatBuffer
    napi_value bufferData = obj->update(env, info);
    
    // 获取事件结果
    napi_value eventResult_v = obj->getEventResults(env);
    
    // 创建返回对象
    napi_value returnObj;
    napi_create_object(env, &returnObj);
    napi_set_named_property(env, returnObj, "bufferData", bufferData);
    napi_set_named_property(env, returnObj, "results", eventResult_v);
    
    return returnObj;
}
```

```cpp
napi_value PhysicsSystem::update(napi_env env, napi_callback_info info) {
    // 检查是否已有缓存的 buffer 引用
    if (buffer_ref_ != nullptr) {
        napi_value result;
        napi_get_reference_value(env, buffer_ref_, &result);
        return result;
    }
    
    // 创建外部 ArrayBuffer（零拷贝）
    FloatBuffer* bufferData = new FloatBuffer{pos_x, capacity * 10};
    
    napi_value arrayBuffer;
    napi_create_external_arraybuffer(
        env, pos_x, 
        capacity * 10 * sizeof(float),
        FinalizeCallback,  // 销毁回调
        bufferData,
        &arrayBuffer
    );
    
    // 创建 Float32Array TypedArray
    napi_value outputArray;
    napi_create_typedarray(
        env, napi_float32_array,
        capacity * 10,
        arrayBuffer, 0,
        &outputArray
    );
    
    // 保存引用
    napi_create_reference(env, outputArray, 1, &buffer_ref_);
    
    return outputArray;
}

// Buffer 销毁回调
void FinalizeCallback(napi_env env, void* finalize_data, void* finalize_hint) {
    FloatBuffer* bufferData = static_cast<FloatBuffer*>(finalize_hint);
    delete bufferData;
}
```

## 11. 性能优化建议

### 11.1 当前优化

| 优化项 | 说明 |
|--------|------|
| SoA 内存布局 | 提升缓存命中率和 SIMD 效率 |
| 零拷贝 FloatBuffer | 避免跨语言数据复制 |
| 自适应子步长 | 动态调整模拟精度 |
| 速度钳制 | 防止穿透 |
| 事件优先级队列 | 触摸事件优先响应 |
| 空闲列表复用 | 避免频繁内存分配 |

### 11.2 未来优化方向

#### 1. 空间分割（降低碰撞检测复杂度）

```
当前：O(n²) 全对全检测
优化：Grid / Octree / BVH → O(n log n) 或 O(n)

实现思路：
- 将空间划分为网格
- 只检测相邻网格中的物体
- 适用于物体分布不均匀的场景
```

#### 2. SIMD 向量化

```cpp
// 当前：标量计算
vel_x[i] += force_x[i] * invMass[i] * dt;

// 优化：使用 NEON/SSE 指令
// 一次处理 4 个节点
float32x4_t vx = vld1q_f32(&vel_x[i]);
float32x4_t fx = vld1q_f32(&force_x[i]);
float32x4_t im = vld1q_f32(&invMass[i]);
vx = vaddq_f32(vx, vmulq_f32(vmulfx, im, dt));
vst1q_f32(&vel_x[i], vx);
```

#### 3. 多线程并行化

```
将物理模拟流水线并行化：
- 碰撞检测：并行遍历节点对
- 速度积分：并行更新节点
- 位置积分：并行更新节点

注意：碰撞求解需要串行（接触点之间有依赖）
```

#### 4. 宽相检测优化

```
在精确碰撞检测前增加粗粒度过滤：
- AABB 重叠测试
- 距离阈值过滤
- 空间哈希表
```

#### 5. 内存池优化

```
当前：一次性分配大块内存
优化：
- 使用内存池管理节点分配
- 避免内存碎片
- 支持动态扩容
```

### 11.3 性能基准参考

| 指标 | 当前值 | 目标值 |
|------|--------|--------|
| 128 节点碰撞检测 | < 5ms | < 2ms |
| FloatBuffer 读取 | < 1ms | < 0.5ms |
| 事件处理 | < 1ms | < 0.5ms |
| 内存占用 | ~20KB | ~20KB（已优化） |
