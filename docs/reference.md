#### aabb包围盒计算

- 我们只关系模型中两层节点，最外层，和特定的部分，不关心更细的部分。
- 所有与3D物体交互的情况都要有一个规则
	- 最外层为空节点表示整个物体
	- 下层的几何节点表示物体的各个部分
	- 场景节点不可被移动
	- 我们进行aabb包围盒的计算则通过两层 空物体 再到真实的集合节点.
	- 移动时只能选中空物体，不能对空物体下的几何节点做分别移动，这样会破坏模型
	- 但是射线检测时可以检测到具体的部分
- （先仅仅计算父节点的位移和缩放，有其它问题再修改）
	- 因为我们只能移动父节点
