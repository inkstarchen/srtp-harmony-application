# 项目介绍

## 3D的用途

- 呈现信息（原本是2D的信息，现在放在3D渲染中去做）
- 实现一些2D做不到的功能：如复杂动画、场景模拟之类的。

## 基础创意
- 遮挡效果：通过UI层级实现
	- 出框效果：遮挡效果的延伸，通过`clip(true)`属性实现画面的截断
    - 光影效果：遮挡的延伸，系统帮我们合成图像，因此可以通过透明体的光影反映在2D组件上.
- 碰撞效果：通过在3D空间内为2D的组件声明虚拟的碰撞体实现。
- 动画联动：主要通过点击2/3D物体触发事件，来带动动画的播放。
- 同一组件对象的23D渲染流转

## 额外创意

- 圆环圈中进行3D渲染，可手指移动视角，点击圆环，视角扩展到全屏。
